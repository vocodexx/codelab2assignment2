This directory is populated by the openFrameworks Project Generator on Windows.

Recommended:
1. Put this WeatherApp folder at:
   <openFrameworks-0.12.1>\apps\myApps\WeatherApp
2. Open openFrameworks 0.12.1 Project Generator.
3. Select this project folder and click UPDATE.
4. The Project Generator will populate the correct DLL dependencies for your exact OF 0.12.1 installation.
5. Re-open WeatherApp.sln and build Debug | x64.

Do not copy DLLs from a different openFrameworks version.
